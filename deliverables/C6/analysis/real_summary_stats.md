## 口径备注

1. 基座速度/姿态/位置取 `/humanoid_mpc_observation` 状态估计输出；状态向量布局经 sim 真值回验（pos corr=1.00000、vel corr=0.99981）。
2. z_c 由 MuJoCo 名义模型正解（zc_lib.com_height），与 6.4.1 仿真侧同口径。
3. 恢复判据：实机 trot-in-place 持续迈步使平滑位移速率中位约 0.04 m/s，「稳住」判据（eps_rate=0.02 m/s）不可用；恢复指标取姿态带口径（|Δφ|,|Δθ|<0.05 rad 持续 1.0 s），与仿真侧 t_rec_att 同式。
4. 力矩误差=/targetTorque−/realTorque 时间域最近邻对齐；实机 /realTorque 为执行侧反馈输出力矩。
5. FALLEN/NOT_RECOVERED 是实验结果不是数据作废；数据有效性看 STATUS（42/42 VALID）。
6. `/battery_state.percentage` run 内恒值、跨 run 随机（N1），与放电积分不自洽，论文不引用 SOC 字段；其余电源/温度通道（母线电压、电流、温度）物理自洽，已入文。
