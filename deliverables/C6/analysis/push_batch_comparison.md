# 扰动实验 旧批 `_0x` vs 新批 `_2x` 对比（2026-10-12）

新批 = 2026-10-12 语义修正后重录（`/realTorque`=qfrc_actuator @500Hz、
力矩界两层对齐、`t_rec` 判据修正、稳态窗加步态收敛下界）。

> 三处判据/采样修正的效果：
> 1. **`t_rec` 判据**（回到原点 → 稳定下来）：假阴性 56 → 2
> 2. **稳态窗**（速度带 → 加步态收敛下界）：v00 duty 0.71/0.83 → 0.50（真值 0.5）
> 3. **`/realTorque` 采样**（29.4 → 500 Hz）：旧批力矩峰值**不可用**
>    （实测同格 27.89 vs 200.00 Nm，漏 86%），报告峰值须用新批
